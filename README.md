# PokéBusca

## Autor

## Descrição
O PokéBusca é uma aplicação web que permite pesquisar Pokémon pelo nome ou número e visualizar informações como imagem, altura, peso, tipos e habilidades.

## API utilizada
- **PokeAPI**
- Documentação: https://pokeapi.co/docs/v2
- Endpoint consumido: `https://pokeapi.co/api/v2/pokemon/{nome-ou-id}`

## Funcionalidades
- Pesquisa de Pokémon por nome ou número.
- Consulta assíncrona usando `fetch`.
- Exibição de imagem, número, altura, peso, tipos e habilidades.
- Mensagem amigável para Pokémon não encontrado.
- Mensagem de validação quando o campo está vazio.
- Interface responsiva para computador e celular.
